QC Types
1. Piping Isometric Check
Piping isometric drawings (PDF) are checked against the Navisworks 3D model and the client inputs: the Piping Material Specification (PMS), P&IDs, Line List, vendor data and other project documents.
2. P&ID Check
The redrawn P&ID (PDF) is checked against the client's original P&ID (PDF). The check confirms that all lines, equipment, instruments, tags and notes have been copied accurately and completely.
3. General Arrangement (GA) Drawing Check
GA drawings (PDF) are checked against the Navisworks 3D model, P&IDs, vendor data and other project inputs.
Short version (for a table or checklist):
 
#	QC Type	Checked Against
1	Piping Isometric Check	Navisworks model, PMS, P&ID, Line List, vendor data
2	P&ID Check	Client's original P&ID (PDF)
3	GA Drawing Check	Navisworks model, P&ID, vendor data
